# QuickNote — Workora Quick Note Application

A responsive, browser-based notes app made with HTML, CSS, and JavaScript.

## Features
- Create, edit, and delete notes
- Search note titles and content
- Filter notes by Personal, Work, Study, or Ideas
- Automatically saves notes in the current browser using localStorage
- Responsive layout for mobile and desktop
- No server, account, or external library required

## Run locally
1. Extract this ZIP file.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Create a note and refresh the page to test browser saving.

## Publish for a public project link (no coding setup required)
### Option A: Netlify Drop
1. Extract this ZIP file on your computer.
2. Open https://app.netlify.com/drop in your browser.
3. If asked, sign in or create a Netlify account.
4. Drag the extracted project folder (the folder containing `index.html`) onto the drop area. If the site requests files instead, drag `index.html` and any project files from inside the folder.
5. Wait for deployment. Netlify will show a public URL ending in `netlify.app`.
6. Open the URL in an incognito/private window to confirm it is publicly accessible.
7. Paste the deployed website URL into Workora's **Project link** field.

### Option B: GitHub Pages
1. Sign in at https://github.com or create an account.
2. Create a public repository, for example `workora-quick-note`.
3. Use **Add file → Upload files** to upload `index.html` and `README.md` from the extracted folder.
4. Commit the files.
5. Open **Settings → Pages**.
6. Under the build/deployment section, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
7. Wait for GitHub Pages to publish and open the provided URL.
8. Paste that public URL into Workora's **Project link** field.

## Important
- Notes are stored in local browser storage. They do not sync between devices or browsers.
- Do not enter passwords, private information, or confidential data.
- A public project URL is not the same as a LinkedIn post. The current Workora portal shown by the user asks for a project link, so submit the hosted project URL there.
- Submission does not guarantee approval or a certificate; the Workora reviewer decides.
